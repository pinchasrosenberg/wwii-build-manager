B00/contracts מקדים מימוש; B03 ו־B07/inventory יכולים להתחיל במקביל. B09/continuity_seam מתחיל אחרי החוזים, ו־B09/final_integration בסוף. B00/runtime_followup צורך את עיצוב B05. הגרף הקנוני נמצא במרשם תחת dispatch_tasks.

לא כל חבילה היא worker אחד. פצל לפי בעלויות והריץ לכל היותר שלושה workers לצד root בסביבה הנוכחית. השמות המדויקים של המודלים והחלופות מופיעים ב־BRIEF; זמינות חשבון וגרסאות חוזים נבדקות לפני שיגור.
