# terrain_world

תחום: `geospatial_temporal`. פרופיל: `IMPLEMENT`.
ברירת מחדל: `gpt-6-sol` / `high`. חלופה בסביבה הנוכחית: `gpt-5.6-sol` / `high`.

זהו כרטיס תפקיד, לא agent מותקן. מודל במשימה מסוימת יכול להשתנות לפי פרופיל הרשומה; הבעלות אינה משתנה. אל תקרא את מלוא מסמך הארכיטקטורה או ארכיון המקורות כברירת מחדל.

## מה בבעלותך
- `world.terrain` — תבליט וגאומטריית קרקע מקומית לשימוש בתנועה, תצוגה וכיסוי.
- `world.surface_material` — סוג פני שטח המספק חיכוך, התנגדות ותכונות פיזיקליות תחומות.
- `world.water_body` — נהר, אגם או אזור ים עם תחום מים, עומק וגובה ידועים או משוחזרים.
- `world.hydrology` — זרימה, הצפה ועבירות מים במודל מוגבל לסביבה שנבחרה.
- `world.building` — מבנה בעל נפח, פתחים, קומות ותמיכות הנחוצות למשחק.
- `world.wall` — קיר כמקטע גאומטרי בעל חומר, עובי, פתחים וכיסוי.
- `world.bridge` — גשר המחבר מקטעי דרך מעל מכשול עם מגבלת מעבר ועומס.
- `world.tree` — עץ או צמחייה עם נפח מעבר, הסתרה וזהות סביבתית.
- `world.road` — מקטע דרך עם חיבוריות, רוחב, משטח ומצב שימוש.
- `world.trench` — תעלה עם חתך, כניסות, כיסוי ומגבלות תנועה.
- `world.locality` — הרכבת שטח מוגבל, מבנים ותשתיות סביב לוקאליות היסטורית אחת.
- `world.coordinate_transform` — המרת קואורדינטות עולם מדויקות למסגרת מקומית במטרים.
- `world.surface_state` — מצב רטיבות, בוץ, שלג/קרח ועקבות על חומר קרקע; הצטברות ושינוי עם הזמן.
- `world.fortification` — הרכבת מחפורת, עמדת מגן, שקי חול ומחסה מחלקי מבנה וחומר.
- `world.obstacle` — מכשול מעבר כגון גדר, מחסום או הריסות עם מעטפת פיזית ויכולת הסרה.
- `world.structure_state` — דלתות ופתחים, נזק למבנה והריסות ברמת פירוט מוגדרת.

## חבילת הביצוע הנדרשת
1. Global invariants + DOMAIN.md + כרטיס זה.
2. TaskSlice עם IDs נבחרים, יעד, קובצי קריאה/כתיבה מדויקים וקבלה.
3. ContractLock עם schema/semantics/version/hash ו־fixture לכל ממשק נצרך.
4. EvidenceSlice מוגבל לדגם/מקום/זמן, או fixture סינתטי מסומן.
5. תקציב context וביצוע, מצב בסיס והוראות handoff.

## תוצר והסלמה
החזר קוד/נתונים/manifest לפי המשימה, בדיקות עם תוצאות בפועל, פערים והפניות למקורות ול־context ששימשו. אל תדווח על סצנת משחק, נכס, בדיקת headset או historical review שלא בוצעו. שינוי אצל בעלים אחר מוחזר כבקשת שינוי; שינוי בחוזה משותף מתואם עם runtime_core/root.
