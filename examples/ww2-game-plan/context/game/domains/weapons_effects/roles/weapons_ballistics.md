# weapons_ballistics

תחום: `weapons_effects`. פרופיל: `IMPLEMENT`.
ברירת מחדל: `gpt-6-sol` / `high`. חלופה בסביבה הנוכחית: `gpt-5.6-sol` / `high`.

זהו כרטיס תפקיד, לא agent מותקן. מודל במשימה מסוימת יכול להשתנות לפי פרופיל הרשומה; הבעלות אינה משתנה. אל תקרא את מלוא מסמך הארכיטקטורה או ארכיון המקורות כברירת מחדל.

## מה בבעלותך
- `equipment.gun` — הגדרת כלי ירייה עם קנה, תושבת, הזנה ומאפייני וריאנט.
- `equipment.projectile` — קליע או פגז עם מסה, ממדים, סוג ופרמטרי השפעה מבוססים.
- `equipment.optic` — כוונת או מכשיר אופטי עם מגבלות שדה ראייה, הגדלה ויישור.
- `weapons.ammunition_compatibility` — התאמת תחמושת, מטען, הזנה ותושבת לווריאנט נשק.
- `weapons.firing_reload` — מצב טעינה, ירי, טעינה מחדש והפרעה לפעולה של נשק קטן או תותח.
- `weapons.ballistics` — מסלול קליע ופתרון פגיעה בתחום מרחק ומהירות שהמודל תומך בו.
- `equipment.barrel` — קנה נשק בעל אורך, קדח, מסה ונקודות חיבור לפי וריאנט.
- `equipment.breech` — מכלול סגירה ותפעול של בית הבליעה, ידני או אוטומטי, לפי תצורה נתונית.
- `equipment.feed_system` — מחסנית, חגורה או הזנה אחרת עם קיבולת, תאימות ומצב נוכחי.
- `equipment.weapon_stock` — קת ומשטחי אחיזה הנקשרים למעטפת נשק ול־anchors אנושיים.
- `equipment.weapon_action` — הגדרת משפחת מנגנון בריחי/ידני, חצי־אוטומטי או אוטומטי ופעולותיו.
- `equipment.weapon_mount` — הגדרת חיבור נשק מקומי לאחיזה, חצובה או פלטפורמה. platform מחזיק transform עולמי ומצב צירי צריח; הנשק צורך אותם.
- `equipment.throwable` — פריט משחק נזרק המורכב מפעולה, מטען, תנועה ואפקט; ללא פרטי בנייה בעולם האמיתי.

## חבילת הביצוע הנדרשת
1. Global invariants + DOMAIN.md + כרטיס זה.
2. TaskSlice עם IDs נבחרים, יעד, קובצי קריאה/כתיבה מדויקים וקבלה.
3. ContractLock עם schema/semantics/version/hash ו־fixture לכל ממשק נצרך.
4. EvidenceSlice מוגבל לדגם/מקום/זמן, או fixture סינתטי מסומן.
5. תקציב context וביצוע, מצב בסיס והוראות handoff.

## תוצר והסלמה
החזר קוד/נתונים/manifest לפי המשימה, בדיקות עם תוצאות בפועל, פערים והפניות למקורות ול־context ששימשו. אל תדווח על סצנת משחק, נכס, בדיקת headset או historical review שלא בוצעו. שינוי אצל בעלים אחר מוחזר כבקשת שינוי; שינוי בחוזה משותף מתואם עם runtime_core/root.
